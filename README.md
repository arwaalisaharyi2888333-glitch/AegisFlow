AegisFlow — نظام متابعة الحضور والإشغال للفعاليات
منصة ويب تفاعلية مصممة لمتابعة أعداد الحضور ومستوى الإشغال في الفعاليات بشكل فوري ودقيق، مع تنبيهات مرئية للحالة التشغيلية وتحديث مباشر للبيانات.
أبرز المزايا
مؤشرات الإشغال الفورية: عرض نسبة الإشغال (occupancy)، عدد الحضور (attendance)، والسعة الإجمالية (capacity) في لوحة واضحة وسهلة القراءة.
تحديد الحالة التشغيلية: تصنيف الحالة تلقائياً إلى حالتين رئيسيتين (ok أو warn) مع ألوان وتمييز بصري يسهل متابعته.
تتبع البوابات: مراقبة حالة البوابات (gatesRouted و gatesNoRoute) وتحديث سجل التحليلات بشكل فوري.
واجهة متجاوبة: تصميم حديث يدعم اللغة العربية ويعمل بسلاسة على مختلف الشاشات.
التقنيات المستخدمة
HTML5 لبناء هيكل الصفحة وعرض البطاقات والمؤشرات.
CSS3 للتنسيق البصري، المتغيرات اللونية (CSS Variables)، وتوزيع الشبكة (Grid / Flex).
JavaScript لإدارة التحديث الفوري للبيانات وحساب نسب الإشغال وحالة البوابات.
طريقة الاستخدام
1. افتح ملف index.html في أي متصفح ويب حديث.
2. راقب بطاقات الإحصائيات وحالة البوابات وسجل التحديثات المباشرة.
